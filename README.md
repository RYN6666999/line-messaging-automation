## 這是在做什麼

使用者（Ryan）想在 **LINE 桌面版** 上，對一批聊天對象依序送出同一則「活動問卷」。動作序列是：

```
點擊(輸入框/綠色選取筐) → 點擊(第二個位置) → 貼上問卷 → Enter 送出 → ↓ 換下一個聊天室
```

為了可重複執行、可調整、可安全停止，用 `pyautogui`（滑鼠/鍵盤）＋ `pynput`（鍵盤偵測）＋ `tkinter`（介面）在 macOS 上實作。

## 最終架構（為什麼這樣拆最乾淨）

經歷多次反覆後，最大的體悟：**「對齊/標記」與「執行/點擊」是兩件事，混在一起會互相干擾。**

- **`auto_click.py`**：100% 純自動化 — **畫面上絕不掛任何蓋在點擊座標上的視窗**。內含：嚴格前景確認、穩健點擊、貼上、Enter、↓ 切換、緊急停止、可選追蹤 log。
- **`mouse_position.py`**：獨立的**對齊工具** — 在半透明標記上顯示點擊座標，自動置頂不消失，方便使用者把 LINE 視窗拖到正確位置（ESC 結束）。

系統性地分離後，「拖動 LINE 視窗導致點擊失效」的問題就煙消雲散。

## 如何執行（最終版）

前置（僅一次）：`python3 -m pip install pyautogui pynput`；並到「系統設定 → 隱私權與安全性 → 輔助使用」把 **終端機** 加進去打勾，`Cmd+Q` 重開終端機。

```bash
# 1) 對齊（雙擊也等價）
python3 scripts/mouse_position.py     # 拖 LINE 把輸入框對到 ①、步驟2 對到 ②，ESC 結束

# 2) 執行自動化
python3 scripts/auto_click.py          # 按 Enter 開始；ESC / 滑鼠甩左上角 停止
```

要改送出內容／次數／座標，全部集中在 `auto_click.py` 上方的「★★ 設定區 ★★」。

## 給面試官的 30 秒結論

我處理的不是「沒有 bug」的題目，而是一堆 **macOS 平台級大坑**：`.py` 雙擊不會執行、多個 Python 干擾套件、輔助使用權限、中文輸入法吃掉貼上、System Events 1002 權限錯誤、以及「齊標記視窗意外擋掉點擊」這類**只有實測才抓得到的問題**。我的方法是：**先做最小可跑版 → 每個功能加上安全閘（測試模式、緊急停止）→ 用追蹤資料量化除錯 → 最後把互相干擾的功能拆成一目了然的架構**。詳細歷程見 `docs/DEVELOPMENT.md`。
